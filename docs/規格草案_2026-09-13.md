# 線控飛機油門控制器 規格草案(2026-09-13)

狀態:**已定案(2026-09-13 第六輪),開始實作**. 實作進度見「開發紀錄.md」.
紀錄:第一輪 ~ 第六輪討論完畢.

## 1. 用途

電動線控特技機(F2B 型態:人在圓心,用鋼索控制升降,飛機繞人做圓周運動).
ESP32-C3 讀 MPU6050 算機頭相對地平線的角度,依時間與角度自動調整電變油門.
**簡單至上**:只做角度判斷,不做角速度預測(第二輪決定).

## 2. 硬體

| 項目 | 定案 |
|---|---|
| 主控 | ESP32-C3 SuperMini |
| 感測器 | MPU6050(I2C,GPIO5/6;GG 2026-09-14 定案,開發板同日從 GPIO0/1 改線;腳位在 pins_config.h),量程 ±2000dps / ±16g |
| 輸出 | 電變一路,50Hz,GPIO4(全板開機最乾淨的腳,避免雜波讓馬達轉動) |
| 供電 | 電變 BEC 供電,板上降壓板支援 6~9V 的 BEC;收腳舵機從 BEC 分電,不經過控制器(GG 2026-09-14) |
| 狀態燈 | 板載藍色 LED(GPIO8),不增加零件 |
| 其他 | 只有電池. 不裝蜂鳴器,OLED,不量電壓 |

USB 與 BEC 同時通電:GG 表示會有保護電路,不必擔心倒灌(第五輪;2026-09-14 確認是二極體反接保護). 因此 USB 供電時可以
先讓 C3 開機,再接電池給電變,手動輸出滑桿也能完成電變校正.

## 3. 飛行流程

1. 通電 → 電變持續收到最低油門完成解鎖,期間不接受啟動.
2. **待機**(燈長亮):等啟動手勢.
3. **啟動手勢**:機身大致水平 + 往機頭方向用力推,G 力超過門檻(可調 0.5~6g,預設 2.0g;第五輪:大飛機人手推不快,下限降到 0.5g).
   **手勢可關閉**(第五輪,資深飛友習慣):關閉時上電後直接倒數(跳過第 3,4 步),時間到啟動馬達.
   關閉時**每次上電只自動啟動一次**,飛完不會再自己倒數,要再飛重新上電. 倒數期間的外力處理照設定;要純粹上電 N 秒啟動,外力設「不理會」.
   不要求先靜止(戶外有風做不到). 手勢成立後馬達不轉(太危險),只用燈號表示.
   **網頁「開始起飛程序」按鈕**(GG 2026-09-14,不用去踢飛機):效果等同做一次啟動手勢,檢查相同(未儲存,感測器,水平限制,扭轉封鎖期);
   只在手勢開啟時的待機/結束出現,按兩下(3 秒內)才送出;上電自動倒數模式不提供(每次上電只飛一次).
   **目前風格有未儲存的變更時,拒絕啟動**(第五輪決定,避免飛一飛忘記儲存).
   拒絕時燈急閃 1 秒再回長亮,網頁寫出原因.
4. **等待靜止**(燈慢閃):飛機放到平地上,靜止而且安全開關按過(GG 2026-09-14,見第 8 節)才進入倒數.
5. **倒數**(燈快閃,秒數可調,預設範圍 15~30 秒).
   偵測到外力介入 → 退回「等待靜止」(慢閃),再次靜止後依設定繼續:
   **延長 N 秒(預設,N 可調,預設 5)** / 重置從頭倒數 / 關閉(完全不理外力).
   延長有上限:不管晃幾次,倒數最多到「倒數秒數 +10 秒」(GG 指定).
6. 馬達以**緩啟動加力秒數**慢慢加到第一段油門(秒數可調). (第三輪回饋:「斜坡」一詞會誤導,網頁一律改稱加力/減力秒數)
7. 第一段:基本油門約 70~80%(可調),持續約 2~2.5 分鐘(可調).
8. 換段到第二段:基本油門約 80~90%(可調). **換段方式三選一**(第四輪回饋):
   (1) 直接跳:第一段時間到立刻變第二段油門.
   (2) 直接跳(有過渡):時間到後依換段加力秒數線性加上去.
   (3) 平均分攤:起飛後就把兩段油門差平均加在第一段時間內,第一段結束剛好到第二段油門.
9. 總飛行時間到(可調) → **降落程序**,**角度補償關閉**:
   - 以降落減力秒數(預設 5 秒)把油門降到降落油門(預設 30%),兩者可調.
   - 維持該油門等觸地:觸地短尖峰超過門檻(預設 3g,判斷法見「觸地提早降落」) **或** 完全靜止 1 秒 → 關馬達(可調).
   - 保險時間 20 秒(可調)內沒判斷到觸地,一樣關馬達.
10. 飛完之後不必重新通電,可再做一次手勢起飛.
   **扭轉機尾取消起飛**(GG 2026-09-13):手勢起飛後(等待放穩或倒數中),抓著機尾繞機背軸轉超過設定角度(預設 45°,0 關閉)就取消,回待機,並停止手勢判定設定秒數(預設 5 秒). 上電自動倒數模式不適用.
   **起飛前水平限制**(GG 2026-09-13):機頭或滾轉超過設定角度(預設 35°)時,啟動手勢一律拒絕;上電自動倒數不開始,等飛機放平並維持 1 秒才倒數;已在等待放穩或倒數中超過則直接取消;原因記在事件紀錄.
   **事件紀錄**:觸發降落,馬達停止,感測器異常等事件與原因(含數值與門檻)記在記憶體到斷電,監看頁一行一行顯示通電後秒數;第一行記開機原因.
11. 取消倒數:網頁「取消」鈕(單按即可),或拔電池.

飛行時間軸從「馬達開始轉」算起,不是從通電算起.
參數從手勢成立起鎖定,回到待機才解鎖.

### 燈號(板載 LED)
| 狀態 | 燈號 |
|---|---|
| 通電後電變解鎖中(約 3 秒,不接受手勢) | 熄滅 |
| 待機,等手勢 | 長亮 |
| 手勢成立,等飛機靜止或等安全開關(上電自動倒數等安全開關也是) | 慢閃 |
| 倒數中 | 快閃 |
| 飛行中,降落中 | 熄滅 |
| 飛完正常停車 | 閃 2 下停一下 |
| 撞擊斷電 | 閃 3 下停一下 |
| 感測器故障 | 極快閃 |

### 網頁緊急停止
飛行中 **連按三下** 才生效(避免誤觸),立即關閉輸出.

### 觸地提早降落(第三輪回饋新增,第四輪改判斷條件)
飛行中不滿意想停止時,讓飛機**正飛水平**貼地滑行,**Z 軸(機背方向)持續抖動**(機輪在地上彈跳,滑行)一段時間,就開始降落程序.
可調:開關(預設關閉),抖動門檻(預設 0.8g),持續秒數(預設 1.0),正飛水平容許角度(預設 ±20°,機頭與滾轉),起飛後幾秒才啟用(預設 10).
抖動 = Z 軸減掉自身 8Hz 低通後的 0.5 秒 RMS. 8Hz 是模擬掃描出來的:3Hz 擋不住直角彎 9g 急變化,筋斗剛回水平時會誤觸發.
(第三輪原本用單一衝擊尖峰判斷,GG 認為不可靠,改成持續抖動.)
降落程序中關馬達的條件:觸地短衝擊(降落觸地門檻)/ 完全靜止 / 地面滑行抖動持續達標(用提早降落的抖動設定,不論開關),任一成立.

### 手勢試推燈(第四輪回饋)
設定頁啟動手勢力道旁邊有指示燈:平常灰色,機身大致水平且機頭方向推力(已扣重力分量)達到設定值時亮綠燈 1.5 秒,顯示達標的最大推力.

### G 力紀錄圖表(第四輪回饋,原第 7 階段提前)
板子持續記錄最近 10 分鐘,每 0.1 秒一筆(區間取最大值,短尖峰不漏):機頭角度,油門,總 G,短尖峰,手勢推力,Z 軸抖動,正飛水平,抖動持續達標.
紀錄頁畫三個面板(角度與油門 / G 力 / Z 抖動)並標出手勢,觸地,抖動門檻線,可點選查看某一時刻數值,顯示視窗內各項最大值.
用途:先關提早降落飛特技,看特技與地面滑行各自的數值再訂門檻. 記在板子上是因為飛行中手機不可能即時接收.

### 撞擊斷電
飛行中任何時候偵測到猛烈撞擊 → **立即關閉輸出**. 門檻可調(預設 14g,晶片上限 16g).

### 網頁狀態顯示
即時顯示目前狀態,倒數剩餘秒數,**上一次結束原因**(正常觸地 / 保險時間到 / 撞擊斷電 / 緊急停止),
**倒數重置或延長的原因**(外力大小:相對飛機原本放著的樣子,這次外力的最大值;2026-09-13 修正原本永遠顯示門檻附近的值),**拒絕啟動的原因**(例如有未儲存變更),感測器是否故障.

## 4. 角度補償

- 最終油門 = 當段基本油門 + 角度補償(加法),再夾在飛行油門上下限之間.
- 飛行油門下限 30%,上限 100%(可調).
- **所有百分比旁邊都顯示實際脈寬 µs**,例如「75%(1750µs)」.
  0% = 1000µs,100% = 2000µs(標準值為預設,兩端可調).
- 補償曲線涵蓋 **-90° ~ +90°**,多段折線(點與點直線相連):
  - 每側:死區邊界 + **1~4 個可調點(使用者自選數量,GG 2026-09-13 從 2~5 改)**. 角度必須由小到大,拖曳不可交叉.
  - 預設(3 點) 朝上:+20°→0% / +45°→+8% / +70°→+15% / +90°→+20%.
  - 預設(3 點) 朝下:-3°→0% / -30°→-10% / -60°→-20% / -90°→-25%.
- **兩段飛行共用一條補償曲線**(第七輪回饋:曾做過兩段各自一條,GG 認為不好設定且易混淆,已刪除).
  角度補償頁「第二段」顯示同一條曲線套上第二段基本油門的結果(曲線不能改,但可拖曳/加減第二段基本油門,與風格頁同一個參數),並做**撞牆檢查**:標出補償後超過上限/低於下限的角度區間與少了幾 %.
- 監看頁姿態圖背景畫油門曲線,並有目前角度紅線與實際輸出點.
- **補償直接照曲線輸出,不加過渡**(反應才即時).
  緩啟動加力秒數,換段加力秒數(線性時),降落減力秒數這三個照時間走的變化保留.
- 馬達啟動後前 N 秒不做補償(後三點式停在地上本來就機頭朝上),N 可調.
- 姿態估算:陀螺儀 + 加速度計融合(Mahony). 繞圈的向心力約 3g,單靠加速度計算角度不可信.
  **向心力補償**(實作時決定,ArduPilot DCM 同一做法):機身座標的向心加速度 = 角速度 × (飛行速度,0,0),
  從加速度計讀值扣掉後再融合. 飛行速度由共用設定的「線長」與「單圈秒數」換算(2π×線長÷單圈秒數),
  只在馬達運轉時套用(地上手拿轉動時速度是 0). 陀螺儀零點在地上靜止時自動學習.
- 不做「放地上歸零」. 網頁顯示**晶片當下量到的實際角度**,使用者自己調安裝方位與角度偏移(預設 0),
  讓飛行時水平的位置讀到 0°.
- 安裝頁的方位設定要有**側視與後視圖**(跟著感測器即時轉,箭頭標出目前哪個晶片軸朝機頭/機背/左翼),
  並**標出出廠預設值**(+X 朝機頭,+Z 朝機背,修正 0°)與「安裝方位回預設」,避免改錯改不回來.

- 分頁:監看 / 風格 / 角度補償(第四輪回饋獨立出來)/ 設定 / 紀錄 / 系統.
- 感測器方位:只選朝機頭與朝機背,朝左翼由右手定則自動決定並顯示(第四輪 GG 問 Y 軸;Y 軸有參與姿態計算,繞圈向心力就在 Y 方向).
- 參數畫面(第三輪回饋):中間數字要比 +/- 按鈕大;曲線每一點的角度與補償放在同一個框內,點與點分開.

### 圖形化介面(第五輪定案)
- 直軸 = 機頭角度(往上=機頭朝上,-90°~+90°).
- **橫軸 = 實際輸出油門 %,按真實比例畫(0~100% 等距)**,刻度同時標 µs.
- 上方分頁切換「第一段 / 第二段」,各自畫出 基本油門 + 補償 後的曲線.
- 油門上下限畫成直線,超出範圍的區域塗灰;曲線碰到限制的那段畫成貼著限制線,原曲線改虛線.
- 左側飛機側視圖示跟著實際角度轉,**預設機頭朝左**(逆時針飛),可切換朝右.
- 監看頁圖示(第五輪):**倒飛時機頭換到另一邊並且上下顛倒**,標示 正飛/倒飛/側飛.
- 紅色橫線顯示當下角度. 標示要明確.
- **基本油門顯示在畫面中間**,同時標百分比與 µs.
- 操作(第六輪定案):
  - 邊框把手:直軸上有死區上緣/下緣,橫軸上有下限/基本油門/上限. 只在邊框範圍內可拖,避免圖內誤觸.
  - 座標內的各點:點一下選中,可直接拖,或用右側面板的 +/- 調整.
  - **選中的點要醒目**(亮紅底 + 光暈).
  - 粗調 5(° 或 %),細調 1(1% = 10µs). 手機上右側面板移到圖的下方.
  - 每側可調點數量 1~4 由使用者選.

### 機輪收腳(GG 2026-09-13 追加)
- 收腳舵機接 **GPIO3**,50Hz 舵機訊號. 設定放**安裝頁**,所有計時器共用.
- 設定:啟用開關(預設關),舵機行程下限/上限 µs(**預設 1400/1600 小行程**,GG:避免還沒搞清楚方向就撞壞),舵機反轉(正轉:放下在下限,收起在上限;反轉相反),
  起飛後幾秒收輪,舵機速度(從一端走到另一端的秒數,0 = 直接跳).
- 時機:馬達啟動後 N 秒收輪;降落**減力階段一開始**放輪.
- **觸地提早降落開啟時收輪不作用**(不知道使用者什麼時候要提早降落,輪子必須一直放著).
- 馬達被迫停下(撞擊斷電,緊急停止,保險時間到)**立即放輪**. 開機,待機,倒數中一律在放下位置.

## 5. 故障處理

感測器讀不到或資料不合理 → 關掉角度補償,**時間軸照跑**(換段,時間到降落停車都照常). 不斷電.
**故障後即使中途恢復也不再採用資料,要重新上電才恢復使用**(GG 2026-09-13;全功能測試發現飛行中恢復時角度讀值會亂擺數秒).
開機後還沒正常讀到過之前的讀取失敗不算(開機時序).

## 6. 飛行風格

- 風格 **A~E + TEST** 共六組. 每組可自行命名,提供「複製到另一組」. TEST 與 A~E 規則完全相同(也要儲存才能起飛).
- 參數有獨立的「儲存」鈕. **有未儲存的變更時不允許啟動**.

| 跟著風格走(飛法) | 全部共用(安裝設定) |
|---|---|
| 兩段基本油門,第一段時間,總飛行時間 | 感測器安裝方位,角度偏移,機頭朝左或朝右 |
| 緩啟動加力秒數,換段方式與加力秒數,降落減力秒數與降落油門 | 1000/2000µs 脈寬端點 |
| 補償曲線(兩側各 1~4 點),油門上下限 | 手勢 G 力門檻,外力門檻,外力處理方式與延長秒數 |
| 起飛後幾秒不補償 | 撞擊斷電門檻,觸地判斷,保險時間,倒數秒數,觸地提早降落(開關/門檻/啟用秒數),線長與單圈秒數 |
| | WiFi 設定 |

## 7. 電變校正與手動輸出(第五輪定案,兩種都保留)

### (a) 電變校正精靈(自動執行)
1. 網頁勾選「下次通電進入校正」並確認「螺旋槳已拆除」.
2. 重新通電. C3 開機後**第一件事**輸出 2000µs,WiFi 之後才啟動.
3. 保持 2000µs 設定的秒數(**預設 4 秒**,可調;GG 2026-09-14 從 2 秒改:電變自己開機要約 1 秒,4~5 秒剛好等電變開機又不會進設定模式)後,**自動**切到 1000µs,完成校正.
4. 旗標開機一讀到就先清除,只生效一次.

### (b) 手動輸出滑桿
待機時用滑桿直接輸出 1000~2000µs(測試轉向,確認油門大小,也可配合 USB 供電做校正).
安全開關:勾選「螺旋槳已拆除」才能解鎖 / 只在待機狀態可用 /
網頁持續送心跳,斷線超過 0.5 秒自動回 1000µs / 離開分頁自動上鎖.

## 8. 系統

- WiFi:先連家用 WiFi,失敗改開熱點;網頁調參數;設定存 NVS;mDNS 網址.
- 熱點名稱(GG 2026-09-13):**開頭固定 HappySuperGG_Plane**,後面可以不接或接字(例 HappySuperGG_Plane3),最多 14 位元組,頭尾不可空白.
  **熱點密碼固定 12345678 不能改**(避免使用者輸入錯誤或忘記). 可改密碼的只有家用 WiFi.
- **WiFi 設定保護**(GG 2026-09-14:裝進飛機後沒辦法插 USB,連不上 WiFi 板子就廢了):
  - 改完要確認:網頁拉發射功率後 15 秒內沒按「保持」自動退回;儲存 WiFi 設定並重開後,WiFi 連上(或開熱點)3 分鐘內沒按「保持」,
    自動改回上一次的設定並重啟 WiFi(不重開板子,飛行中也安全). USB 序列指令(wifi / txp)不需要確認.
  - 連續開關電 3 次救援:每次通電不到 5 秒就斷電,連續 3 次 → WiFi 設定回出廠(自身熱點 HappySuperGG_Plane,5dBm,清除家用 WiFi 與熱點後綴).
    只算真正斷電再上電,軟體重開/OTA 不算. 飛行設定不動. 記進事件紀錄.
- 飛行中 WiFi 保持開著,網頁只能看不能改. 馬達轉動時鎖住 OTA 與參數修改.
- OTA:保留. 分割表改成支援 OTA 的版本(參考專案用的 huge_app 不支援 OTA).
- **遠端更新**(GG 2026-09-14:板子送人後,對方自己在網頁更新 GG 準備好的版本):
  - GG 另開**公開** GitHub 專案 licni/ESP32lineplane-firmware,只放韌體檔與 manifest.json(版本,大小,SHA-256,檔名,更新說明),不放原始碼.
  - 網頁「系統 → 韌體更新」:檢查更新 → 顯示新版說明 → 按兩下確認 → 板子自己 HTTPS 下載,大小與 SHA-256 符合才切換,完成自動重開.
    版本「年.月.日.序號」逐段比數字,**網站版本比板子新才提示與安裝**(GG 2026-09-14:原本只比相不相同,板子 .12 網站 .11 也說有新版本).
    需要家用 WiFi 能上網;自身熱點模式不能檢查. 有未儲存設定時不能更新(重開會丟掉).
  - 保護 1:只有待機能開始,更新中拒絕起飛與手動輸出. 網頁上傳與無線燒錄也一樣.
  - 保護 2:新韌體第一次開機是「待確認」,打開網頁自動確認;WiFi 就緒後 **1 分鐘**內沒確認,自動退回舊版(ESP32 內建 rollback;GG 2026-09-14 從 5 分鐘改 1 分鐘:正常人不會等那麼久,家用 WiFi 隨時可連).
    開機後最久等 4 分鐘(WiFi 一直沒就緒時). 更新時要保持網頁開著.
    確認前不能起飛(飛行中退回重開等於馬達停);確認前斷電或重開也會退回. 退回後舊版網頁提示「上次更新沒確認,已退回」.
- **起飛安全開關**(GG 2026-09-14 安全審查後決定):微動開關接 GPIO21 與地(建議串 1kΩ),內部上拉.
  **同日 GG 改規則**:起飛程序(推飛機手勢,網頁「開始」,上電自動倒數)照常開始,**等安全開關按下才開始倒數**
  (原本是開始那一刻沒按下就拒絕,原因 7/8,不再使用). 按下 = 低電位去抖 50ms.
  手勢或網頁開始:進入等待放穩,放穩而且按過開關才倒數;放穩前後按都可以,按一次就記住,開始當下按著也算(飛場應急短路照樣能飛).
  上電自動倒數:電變解鎖後在待機等(燈慢閃),按過開關而且放平維持 1 秒才倒數;開機時已按著則解鎖完直接倒數.
  倒數中外力介入退回等待放穩,重新放穩後繼續倒數,不必再按. 倒數與飛行中放開不影響. 沒接開關或線斷掉 = 永遠不會倒數.
  網頁狀態列顯示「等待安全開關」,監看頁顯示開關狀態,事件紀錄 28(已放穩等開關 / 上電自動倒數等開關 / 開關按下).
  **等待上限**(GG 2026-09-14,設定頁「安全開關等待上限」,出廠 3 分鐘,1~30 分鐘):起飛程序開始後超過上限還沒按開關 → 取消回待機(設定解鎖,事件 28/3);
  上電自動倒數從解鎖完開始算,逾時就不再等,這次通電不再自動倒數(事件 28/4). 按過開關就不再計時. 等待中狀態列顯示剩餘時間.
- **電變校正旗標時效**(GG 2026-09-14):按「下次通電進入校正」後 10 秒內沒拔電就自動取消;軟體重開也取消. 網頁按鈕旁醒目提示.
- **撞擊斷電後推飛機不算手勢**:要網頁「開始起飛程序」或拔電再接電. **飛行中油門下限最低 10%**. **起飛程序與飛行中不能改 WiFi,發射功率,檢查更新**,WiFi 試用計時暫停到落地.
- **撞擊斷電**改為連續 2 拍(10ms)超過門檻才觸發(安全審查 B1):單筆感測器錯誤資料不會在空中關馬達.
- **開機安全**(GG 2026-09-14):「上電後直接倒數」只給真正的拔電再接電. OTA 更新完,網頁重開機,當機或電壓不足重開都停在待機,
  事件紀錄標明「這次不是拔電再接電」. 手勢起飛與網頁開始按鈕不受影響.
- 飛行紀錄:角度,油門,每秒 10 筆,存在記憶體,降落後在網頁看曲線,重新通電才清除.
